# HoopLoop Platform 24 / Pack, Pull, Play v3

This update focuses on cleaning and clarifying Pack, Pull, Play.

## What changed

- Most pre-1990 fringe players were removed; only iconic / high-recognition stars remain from that era.
- The player-facing card surface now emphasizes **photo + team-era label + playstyle**.
- Generic visible `CURRENT` cards were replaced with cleaner modern-team style labeling.
- Every Pack, Pull, Play card now has a playstyle label.
- The broader card pool remains large at **1,101 total versions**.
- The season result now frames the stat table as simulated role output.
- PPP still uses the existing backend from `supabase/pack-pull-play-v1.sql`.

## Install

1. Back up your working HoopLoop repository.
2. Extract `hooploop-platform-24-pack-pull-play-v3.zip`.
3. Copy the contents of `hooploop-platform-24-update` into the root of your HoopLoop repository.
4. Replace matching files.
5. Preserve `config.js`.
6. Push and hard-refresh `verify.html`.

## SQL

**No new SQL is required.**

This update remains compatible with the existing PPP v1 backend.
