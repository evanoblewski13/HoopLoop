# HoopLoopSim Alpha 0.5

HoopLoopSim is HoopLoop's customizable, local-first basketball career simulator.

Alpha 0.5 is the first release under the HoopLoopSim name and adds:

- International HoopLoop League
- 50 international country-team identities
- 16–36 team international leagues (24 default)
- Fixed 12-team international playoffs with top-four byes
- Rebalanced rebounds, assists, steals and blocks
- Rare season-level statistical outliers
- Randomize Player creator control
- League Stats scope/team filters
- Trade-request confirmation
- Automatic roster view after user team movement
- Mobile playoff-centering fix
- Trophy/award text layout cleanup

The domestic 80-team mode, multi-season career system, offline saves, draft, free agency, trades, box scores, League News, retirement and Hall of Fame systems remain available.

## Preferred URL

`hooploopsim.html`

`hoopsim.html` is retained as a redirect for compatibility with older links.

## Install

Read `HOOPLOOPSIM-0.5-UPDATE-GUIDE.md` before copying files into GitHub.

No Supabase or SQL changes are required.
