## Open locally

Double-click `index.html`.

## Verify the database

Double-click `verify.html`. All checks should pass.

## Clean GitHub restart

Follow `RESET-GUIDE.md` exactly. The safest approach is to rename the old repository, create a brand-new `hooploop` repository, and copy only the Version 4 root files.

## Important architecture note

This remains a front-end prototype. Accounts, friendships, and leaderboards use browser storage. A real multi-device platform still requires a backend such as Supabase.
