1. Start from the working corrected Platform 25 + Platform 26 repo state.
2. Extract this ZIP.
3. Copy the contents of `hooploop-platform-27-update` into the repository root and replace matching files.
4. **Do not delete** `config.js`, `players-data.js`, `styles.css`, `script.js`, Supabase migrations, or HoopLoopSim save data.
5. Commit and push.
6. Hard-refresh `index.html` and `verify.html`.
