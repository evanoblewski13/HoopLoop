# HoopSim Alpha 0.3 test checklist

## Creator and draft

- [ ] Default player name is Evan Oblewski.
- [ ] Typing fewer than 14 games clamps to 14 after leaving the field.
- [ ] Typing more than 99 games clamps to 99.
- [ ] Minus and plus season buttons appear and work on mobile.
- [ ] Manual Draft reveals one pick at a time.
- [ ] Each manual pick shows player size, playstyle, overall, and top attributes.
- [ ] Simulate remaining picks finishes the draft.
- [ ] Undrafted players receive exactly three offers.

## Players and statistics

- [ ] Clicking a player in Rosters opens a full profile.
- [ ] Clicking a player in League Stats opens the same profile.
- [ ] Clicking a statistical column sorts the table.
- [ ] Clicking the same column again reverses the order.
- [ ] Career History displays full season averages and shooting percentages.
- [ ] Hall of Fame probability stays hidden until age 30 or 10 completed seasons.

## Playoffs

- [ ] Sim one game per series advances every unfinished series exactly once.
- [ ] The next round does not begin until every current series is finished.
- [ ] User playoff games appear in Recent Games.
- [ ] User playoff games also appear in the postseason game log.
- [ ] The bracket shows seeds, series scores, and individual game scores.
- [ ] Playoff simulation keeps the page near the postseason section.

## Offseason and saves

- [ ] Development lists every attribute vertically as old → new (change).
- [ ] Alpha 0.2 saves load and retain their career.
- [ ] Export still downloads a JSON backup.
- [ ] Six career slots remain supported.
