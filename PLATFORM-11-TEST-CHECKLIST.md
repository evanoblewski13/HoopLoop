# Cash Grab v3 test checklist

## Board
- [ ] Current and All-Time are the only player modes.
- [ ] Each $1-$5 column appears G, G, F, F, C.
- [ ] Daily board stays identical after refresh.
- [ ] Random board changes when rerolled.

## Normal 5v5
- [ ] Five-player roster cannot exceed $15.
- [ ] CPU opponent has five unique players and none are on the user team.
- [ ] Game states 40 minutes / 5v5 / no stamina or injuries.
- [ ] Quarter line score appears.
- [ ] Both teams have complete box scores and every player has 40 MIN.
- [ ] Result no longer contains the old explanatory paragraph.

## Gauntlet
- [ ] Opponent has no duplicate players and no players from the user lineup.
- [ ] Checklist uses only rounds 1-10 with ✓ / × / current marker.
- [ ] Daily board offers one official attempt when logged in.
- [ ] Refreshing does not reroll a Daily round result for the same lineup.
- [ ] Past Daily dates remain playable as practice.
- [ ] Daily leaderboard ranks rounds cleared, point differential, points scored, then completion time.

## Snake Draft vs CPU
- [ ] First picker is randomized.
- [ ] Pick order follows P1, P2, P2, P1, P1, P2, P2, P1, P1, P2.
- [ ] Drafted players cannot be selected twice.
- [ ] A pick cannot exceed $15 or leave insufficient budget to finish five players.
- [ ] Any position combination is allowed.
- [ ] Final game includes full box score.

## Real-player Draft
- [ ] Friend invite appears in Draft Battles.
- [ ] Friend accepts and both users see the same board/picks.
- [ ] Random matchmaking creates a shared draft board.
- [ ] Turns update live through Realtime.
- [ ] Final game/result is the same for both players.
