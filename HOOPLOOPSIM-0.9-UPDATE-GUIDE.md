# HoopLoopSim Alpha 0.9 — Update Guide

No Supabase or SQL changes are required.

1. Export any important HoopLoopSim save as a backup.
2. Extract the Alpha 0.9 ZIP.
3. In GitHub Desktop, select the HoopLoop repository and choose **Repository → Show in Explorer**.
4. Copy the contents of `hooploopsim-alpha-0.9-update` directly into the repository root.
5. Replace matching HoopLoopSim files. Do not delete unrelated HoopLoop files such as `config.js`, Name Rush data, SBC data, or `supabase/`.
6. Commit with `Balance HoopLoopSim Alpha 0.9`.
7. Push origin and wait for GitHub Pages to finish.
8. Open `https://YOUR-USERNAME.github.io/hooploop/hoopsim-verify.html`.
9. Hard refresh with **Ctrl + Shift + R**.

Alpha 0.8 +5-rating saves migrate automatically and only once to the +10 model while preserving displayed overall.
