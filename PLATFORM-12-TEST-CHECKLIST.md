# Cash Grab v4 / Platform 12 Test Checklist

## Box score realism
- [ ] Play at least 10 Bot/Gauntlet games.
- [ ] Team FGA totals are usually fairly close.
- [ ] If one team has noticeably more FGA, ORB / turnovers / FT volume explain most of the difference.
- [ ] Box scores show ORB as well as total rebounds.
- [ ] Individual stat lines feel less repetitive.
- [ ] Occasional 40+ point games appear.
- [ ] A 50+ point game can happen, but does not happen constantly.

## Matchups
- [ ] Both lineups appear in PG → SG → SF → PF → C order.
- [ ] The matchup strip clearly shows who is guarding whom.
- [ ] Box-score rows show the direct defender beneath each player's name.
- [ ] Strong defenders appear capable of suppressing opposing scorers.
- [ ] Weak defensive matchups sometimes create explosive scoring games.

## Game Story
- [ ] Generic “Fit counts for 50%...” result copy is gone.
- [ ] Game Story instead calls out actual performances / possession differences / difficult matchups.

## Gauntlet / Hall of Five
- [ ] Finish a Gauntlet run.
- [ ] The completed lineup appears in Hall of Five.
- [ ] Reusing the same lineup with a worse result does not replace its better run.
- [ ] A better result with the same lineup updates it.
- [ ] Only the five best unique lineups remain.
- [ ] Logged-in Hall of Five survives a second device/browser after the v4 SQL migration.
- [ ] Guests still have a local-device Hall of Five.

## Regression
- [ ] Current and All-Time boards still work.
- [ ] Daily boards and one official attempt still work.
- [ ] Gauntlet opponent duplicates are still blocked.
- [ ] CPU snake draft still works.
- [ ] Friend/random snake drafts still work.
- [ ] Existing v3 finished draft results can still be opened.
